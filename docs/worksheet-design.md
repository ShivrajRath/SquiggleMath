# SquiggleMath worksheet design system (ages 3–7)

This is the shared contract for the worksheet rebuild. Every page uses the same
engine (`engine.js`) and the same age-band CSS (`worksheet-ages.css`, loaded
after `styles.css`).

## Why this exists

The old sheets used one density for every age: 11.5px instructions, 28px
equations, 3–4 columns of cards and up to 20 items. That is a Kindergarten /
Grade 1 density. A 3-year-old needs roughly **double the visual area per item**
and a third of the items. Age is the primary design variable, not a badge.

## The three bands

| | Pre-K (3–4) | Kindergarten (5–6) | Grade 1 (6–7) |
|---|---|---|---|
| Items per sheet | 4–8 | 8–20 (default 12) | 10–20 (default 15) |
| Max columns | 2 | 3 | 3–4 |
| Instruction text | 14–15px + picture steps | 12.5px + 2 steps | 11.5–12px |
| Equation size | 30px (rare) | 30px | 27px |
| Answer box | 56 × 44 | 46 × 34 | 54 × 36 |
| Counting pictures | 34–38px | 24–26px | 20px |
| Tracing glyph | 76px, 1 per row + 2 tries | 58px | 52px |
| Large motor target | ≥44px tall | ≥40px | ≥32px |
| Fine-motor goal | paths, tracing, colouring | writing numerals | written equations |
| Grown-up support | Grown-up Corner tip | short tip line | none (independent) |
| Fun layer | mascot cheer, picture steps, star colouring | mascot cheer, mini challenge | challenge box, show-your-thinking |

Rule of thumb: **Pre-K = fewer, bigger, calmer.** Kindergarten = more items but
with picture support. Grade 1 = efficient practice with one thinking task.

`ws-steps` + `ws-grownup` for Pre-K, `ws-mascot` for Pre-K/K, `ws-challenge` for
K/G1. `worksheet-ages.css` may hide any block if space is tight, but must never
hide `.ws-instruction` or `.ws-reward`.

## Evidence notes

The bands above are a design synthesis, not arbitrary taste:

- **NAEYC developmentally appropriate practice** treats worksheets as a short,
  adult-guided option, not the main instructional tool, and warns against
  isolated drill as evidence of learning.
- **Head Start Early Learning Outcomes Framework (ELOF)** places accurate
  counting of about five objects and numeral recognition 0–5 in the 4-year-old
  band, AB patterns at 3–4, and copy-after-model pre-writing strokes (vertical,
  horizontal, circle) before letter/number accuracy.
- **Common Core K–1** sets the content ceiling used here: K = counting and
  operations within 10, teen numbers as ten + ones, direct measurement, 2D/3D
  naming; Grade 1 = facts within 20, two-digit place value, 10 more/less, time
  to hour/half-hour, nonstandard units, halves/fourths.
- **Clear-print accessibility guidance** (e.g. UKAAF) puts the practical floor
  at 12pt with 14pt+ preferred. Our adult-read instruction lines sit at 11–15px
  on the A4 canvas; child-facing labels, equations and boxes are deliberately
  much larger. If a sheet needs more items to fit, cut items — never shrink the
  type.

Practical caps that follow: Pre-K 4–6 responses on one page, two columns,
1/3+ white space; Kindergarten 6–10 responses with picture support on every
item; Grade 1 10–15 responses with one model and one challenge.

## Copy rules

- Ages 3–4: short sentences, one idea per line, "grown-up" language.
- Ages 5–6: playful but direct; name the skill.
- Ages 6–7: confident, a little cheeky; no baby talk.
- Never use an emoji as the only cue for an instruction.
- Keep the theme nouns from `THEMES[theme].items` and characters from
  `THEMES[theme].characters` so every sheet feels bespoke.
